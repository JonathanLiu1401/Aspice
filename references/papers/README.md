# Papers

`BAG3pp.pdf` is Guo et al., "BAG3++: An Extensible Generator Framework for
Automated Layout-Aware AMS Design," IEEE Open Journal of Circuits and Systems,
2025, DOI 10.1109/OJCAS.2024.3502641. The authors released it under
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

Han et al., LAYGO, IEEE TCAS-I, March 2021, DOI 10.1109/TCSI.2020.3046524, is
not in this repo. The PDF from IEEE Xplore says personal use is permitted and
republication requires IEEE permission, and the copy on this machine is licensed
only to University of Washington Libraries.
